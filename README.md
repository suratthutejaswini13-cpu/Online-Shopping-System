Online Shopping System

Project Overview

The Online Shopping System is a Database Management System (DBMS) project designed to manage customers, products, orders, payments, shipments, and product reviews.

Objectives

- Store and manage customer information.
- Organize products and categories.
- Maintain order, cart, and payment details.
- Track shipments and customer reviews.
- Apply primary keys, foreign keys, and SQL queries.

Technologies Used

- SQL
- Relational Database Management System (RDBMS)

Database Tables

1. Customer
2. Category
3. Product
4. Address
5. Orders
6. Cart
7. Payment
8. Shipment
9. Review

- "online_shopping.sql" – SQL implementation of the database.

Conclusion

This project demonstrates database design, relationships, constraints, and SQL operations for an online shopping application.
